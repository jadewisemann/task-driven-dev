# Task Driven Development

사람이 합의한 설계, 작업별 결정과 진행 기록, 코드에서 확인한 구현 지식을 나누어 관리하는 작업 방식입니다. 이 저장소는 그 기본 구조와 프로젝트에 적용하는 부트스트랩 절차를 정의합니다.

| 문서 | 답하는 질문 |
| --- | --- |
| [DESIGN.md](DESIGN.md) | 전체 구조와 책임, 지켜야 할 원칙은 무엇인가? |
| [design/](design/index.md) | 영역별 구조와 책임은 무엇인가? |
| [work/](work/index.md) | 이번 작업의 범위, 승인 상태, 남은 일은 무엇인가? |
| [WORK 양식](work/templates/WORK.md) | 작업을 어떤 항목으로 기록하는가? |
| [knowledge/](knowledge/index.md) | 실제 구현에서 확인한 사실과 근거는 무엇인가? |
| [AGENTS.md](AGENTS.md) | 사람과 AI는 어떤 순서와 제약으로 작업하는가? |
| [BOOTSTRAP.md](BOOTSTRAP.md) | 기존 또는 새 프로젝트에 어떻게 적용하는가? |

현재 제공하는 것은 문서 구조와 수동 적용 절차입니다. 자동 설치, 검사 스크립트, Git 훅, OKF·Graft 연동은 아직 없습니다. 문서에 적힌 규칙이 도구로 강제되는 상태는 아닙니다.
